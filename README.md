## How to use it

To use this webapp:
1. Clone the repository to your local machine, 
2. run `npm install` to install all the required dependencies and
3. run `npm start` to view the website locally.
4. run "node ./backend/server.js"
Feel free to edit and make changes. 


Problem Statement
Effective online communication is essential for collaboration, yet many existing platforms either lack intuitive organization, restrict customization, or have privacy concerns. Users often struggle with managing multiple conversations, navigating cluttered interfaces, and ensuring secure, role-based interactions in group discussions and private messages.

Proposed Solution
ChatHaven is a streamlined communication platform designed to provide seamless interaction through structured text channels and direct messaging. By integrating **role-based user permissions, team-based channel management, and Firebase authentication**, ChatHaven ensures an **organized, secure, and user-friendly messaging experience**. With a clean interface and robust backend, the platform will facilitate efficient collaboration for teams, communities, and personal use.
